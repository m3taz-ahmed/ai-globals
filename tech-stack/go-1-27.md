[TECH] Go 1.27 (released Aug 2026, latest 1.27.0)
[OBJ] Go programming language — generic methods, `encoding/json/v2` + `encoding/json/jsontext`, `crypto/mldsa` (post-quantum ML-DSA), `goroutineleak` profiling GA, size-specialized small allocations (~30% faster <80B), SIMD improvements.
[RULES]
1. [REQ] Use generic methods (methods can now declare type parameters): `func (s Set[T]) Merge(other Set[T]) Set[T]`. Enables type-safe generic method definitions.
2. [REQ] Use `encoding/json/v2` + `encoding/json/jsontext` for JSON handling — improved performance, cleaner API, streaming support. Replaces `encoding/json` for new code.
3. [REQ] Use `crypto/mldsa` for post-quantum ML-DSA signatures — NIST PQC standard. Future-proof crypto against quantum attacks.
4. [REQ] Use `goroutineleak` profiling in `runtime/pprof` (now GA) — detect goroutine leaks in production.
5. [REQ] Leverage size-specialized small allocations (~30% faster for <80B allocations) — automatic, no code change needed.
6. [REQ] Use `new(expr)` initializer to allocate + initialize in one expression.
7. [REQ] Use `go fix` modernizers to auto-migrate code to latest idioms: `go fix ./...`.
8. [REQ] Use `log/slog.NewMultiHandler` to fan-out logs to multiple handlers.
9. [REQ] Use `errors.AsType(err, &target)` for typed error extraction.
10. [REQ] Use `simd/archsimd` for architecture-specific SIMD intrinsics (arm64 Neon + WASM 128-bit SIMD).
11. [REQ] Maintain Go 1 compatibility — code must compile on prior Go 1.x releases unless using new APIs.
12. [REQ] Use `go mod tidy` + `go mod verify` before commits.
13. [REQ] Use `context.Context` as first parameter in all public functions taking requests.
14. [PROHIBIT] Never hand-roll crypto — use `crypto/mldsa`, `crypto/hpke`, `crypto/*` stdlib packages.
15. [PROHIBIT] Never use `unsafe` for SIMD — use `simd/archsimd`.
16. [CMD] `go fix ./...` — auto-migrate to 1.27 idioms.
17. [CMD] `go test ./... -cover` — full test suite with coverage.
[COMPAT]
- Go 1.27 maintains Go 1 compatibility promise.
- Requires macOS 13 Ventura or later (Go 1.26 was last for macOS 12).
- New: generic methods, `encoding/json/v2`, `crypto/mldsa`, `goroutineleak` GA, size-specialized allocations.
- SIMD: arm64 Neon 128-bit + WebAssembly 128-bit SIMD support.
