[TECH] Application Security Hardening Matrix
[OBJ] The canonical vuln→defense reference for every domain aiZee touches — web/API, Python, desktop, server edge, LLM/agent. Load for security reviews, audits, and any feature touching trust boundaries.
[RULES]
1. [REQ] OWASP Top 10 2025 — audit against the CURRENT edition: A01 Broken Access Control (incl. BOLA/BFLA + SSRF rolled in), A02 Security Misconfiguration, A03 Software Supply Chain Failures, A04 Cryptographic Failures, A05 Injection, A06 Insecure Design, A07 Authentication Failures, A08 Software/Data Integrity Failures, A09 Security Logging & Alerting Failures, A10 Mishandling of Exceptional Conditions (NEW — fail-open defaults, catch-and-continue, half-applied states).
2. [REQ] A01 Access control: object-level authz on EVERY resource (BOLA/IDOR), function-level authz on every endpoint (BFLA — direct URL calls), deny-by-default, ownership checks inside handlers not just middleware, SSRF egress allowlists (resolve+pin IP, block metadata ranges, no redirects to internal).
3. [REQ] A02 Misconfiguration: security headers pack on every response (CSP, X-Content-Type-Options=nosniff, frame-ancestors, Referrer-Policy, HSTS after HTTPS verified), `server_tokens off`, hidden files denied (`/.env`, `/.git`, backups), debug/tooling endpoints dead in prod, default creds rotated, CORS allowlist-per-env never `*` with credentials.
4. [REQ] A03 Supply chain: pinned deps (lockfile + SHA/digest), audit tooling in CI (npm audit/pip-audit/composer audit/Trivy), SBOM per release, no freshly-published unvetted versions (minimumReleaseAge), verify package names (typosquatting — pip/npm especially), license scan for commercial work.
5. [REQ] A04 Crypto: TLS 1.2+ only (1.3 preferred), Argon2id/bcrypt passwords (cost tuned), AEAD ciphers (AES-GCM/ChaCha20-Poly1305), NO MD5/SHA1/DES/ECB/custom crypto, keys in KMS/manager never code, secure random (`secrets`/`crypto.randomBytes` — never `random`/MT).
6. [REQ] A05 Injection family — ALL of it, not just SQLi: parameterized queries (SQLi), context-aware escaping (XSS — HTML/attr/JS/URL/CSS differ), command args as arrays never `shell=True`/string concat (cmd inject), DTDs+external entities disabled (XXE), templates never render raw user input (SSTI), expression-language/JNDI-style eval banned (injection via config), ReDoS-prone regex on user input (nested quantifiers) banned, path ops normalized+confined (traversal), open-redirect targets allowlisted.
7. [REQ] A07 AuthN/session: session id regenerated on login, HttpOnly+Secure+SameSite cookies, idle+absolute expiry, MFA on sensitive ops, brute-force throttling + lockout/backoff on auth endpoints, JWT alg pinned server-side (reject `none`, no RS256→HS256 confusion), exp/aud/iss enforced, tokens never in URLs.
8. [REQ] A09 Logging/alerting: security events logged (authz denials, auth failures, privilege changes, rate-limit trips) WITHOUT PII/secrets, correlation ids, alerts on patterns not single events, tamper-evident audit trail, log injection sanitized (newlines/ANSI stripped).
9. [REQ] A10 Exceptional conditions: fail-CLOSED defaults (authz/deny on error — never `except: allow`), no half-applied states (transactions/rollbacks on partial failures), exceptions carry context for ops but generic for clients, retries bounded, circuit breakers on dependencies.
10. [REQ] CSRF: SameSite=Lax/Strict cookies; state-changing requests verify Origin/Referer OR CSRF token (double-submit or synchronizer) — SameSite alone insufficient for GET-side effects and some flows; no state change via GET.
11. [REQ] Clickjacking/redirect/pollution: `frame-ancestors` CSP or X-Frame-Options on every page; open-redirect destinations allowlisted before redirect; `Object.freeze`/schema-strict JSON merge for user objects (prototype pollution — reject `__proto__`/`constructor` keys), `hasOwnProperty` guards on user-keyed objects.
12. [REQ] Python-specific AppSec (bandit-grade): `subprocess` with arg lists never `shell=True` + untrusted input; `eval`/`exec` on anything dynamic banned; `yaml.safe_load` only (never `yaml.load`); `pickle`/`dill`/`marshal` on untrusted bytes = RCE — never; `assert` is not a security check (stripped with -O); `tempfile.mktemp` racy (use `mkstemp`/`NamedTemporaryFile`); `requests/httpx` `verify=True` always; venv isolation + `pip-audit`/`bandit`/`ruff --select S` in CI; `urllib` URL parsing traps (`@`, userinfo) for SSRF; `os.path.join` + `realpath`+prefix check for traversal.
13. [REQ] Desktop-app security (PySide6/Flet/pywebview/NiceGUI): secrets via OS keyring (`keyring` lib → Credential Manager/Keychain/libsecret) — NEVER QSettings/.ini/plaintext; local HTTP servers (NiceGUI/Flet webview modes) bind 127.0.0.1 + per-session token — unauthenticated localhost APIs = any-process takeover; auto-updates require signed packages + HTTPS + verified signatures (unsigned updater = RCE); custom URL schemes/deep links validate every parameter (they're remote input); WebView/JS-bridge (`js_api`) exposes Python methods — treat as a public API surface, validate+minimize; file handlers sanitize paths; clipboard/drag-drop data is untrusted input.
14. [REQ] Server edge: TLS managed+strong ciphers, security headers at proxy, `server_tokens off`, deny hidden/dotfiles, rate-limit auth+expensive routes at edge, upload size caps, request timeouts, upstream never exposed without authn, admin panels IP-allowlisted or Tailscale-only.
15. [REQ] LLM/agent layer (delegate to `security-lord`/`security-auditor`): OWASP LLM Top 10 2026 + ASI Top 10, prompt injection (cross-modal + memory persistence), tool-poisoned MCP servers, excessive agency (SARC gates), unbounded consumption (budgets+circuit breakers), vector poisoning, output handling, provenance/safetensors, secret exfiltration via agent tools — every agent on ANY project gets these gates.
16. [REQ] Data leaks & exfiltration: PII classified + minimized, never in logs/URLs/analytics/client bundles; error messages never leak internals; backups encrypted; exports/downloads authz-scoped per object; third-party pixels/webhooks carry no sensitive params.
17. [REQ] Verification discipline: run the scanner (bandit/ruff-S/npm audit/pip-audit/Trivy/ZAP) AND manually trace trust boundaries — tools miss design flaws (A06/A10); every finding states entry→sink path.
18. [PROHIBIT] "HTTPS fixes everything" thinking (app-layer vulns survive TLS), client-side validation as the only guard, `try/except: pass` around authz/validation, security as a pre-launch-only event (it's per-change), or trusting framework defaults without verifying (CSP off, introspection on, debug on).
[COMPAT]
- OWASP Top 10:2025 (final): two new categories vs 2021 — A03 Supply Chain (expanded) + A10 Exceptional Conditions; SSRF consolidated into A01.
- OWASP LLM Top 10 2026 + ASI Top 10 2026 for the agent layer — covered in `security-lord`/`security-auditor`.
- Scanner mapping: Python `bandit`+`ruff S`+`pip-audit`, JS `npm audit`+`eslint-plugin-security`, PHP `composer audit`, containers `trivy`/`grype`, DAST `zap`.
