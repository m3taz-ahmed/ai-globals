[TECH] seo-1
[OBJ] SEO technical standards and audit rules (2026, aligned with Google Search Essentials + AI Optimization Guide + Quality Rater Guidelines).
[RULES]
1. [REQ] Meta Tags: Title 50-60 chars, Description 150-160 chars, OG tags (og:title/og:description/og:image), Twitter Cards (twitter:card/twitter:title/twitter:description). One H1 per page. Meta viewport for mobile.
2. [REQ] Canonical: Self-referencing `rel="canonical"` on every indexable page. ⛔ canonical pointing to different URL without intent. ⛔ canonical chains.
3. [REQ] Sitemap: XML at `/sitemap.xml`. Dynamic generation. Max 50K URLs/file, 50MB/file. Submit to GSC + Bing Webmaster + IndexNow. Sitemap index for large sites. Cross-reference with crawl: flag URLs missing from sitemap.
4. [REQ] Robots.txt: Allow public content, disallow admin/routes. Reference sitemap (`Sitemap: https://example.com/sitemap.xml`). AI crawler rules: GPTBot, ClaudeBot, PerplexityBot, Google-Extended, CCBot. ⛔ block essential content.
5. [REQ] Hreflang: Correct language-region codes (`en-US`, `ar-EG`, not `en-us`). Return tags (bidirectional). `x-default` for fallback. Content parity across locales. Multi-language sitemaps.
6. [REQ] Schema JSON-LD: Active: Organization, WebSite, Article, Product, BreadcrumbList, LocalBusiness, Event, Person, JobPosting, Course, Review, AggregateRating. E-commerce: ProductGroup, Offer, hasMerchantReturnPolicy, shippingDetails. ⛔ Deprecated: HowTo (Sept 2023), SpecialAnnouncement (July 2025), FAQPage (no rich results May 2026 — use QAPage for genuine Q&A). Dual validation: Rich Results Test + Schema Markup Validator.
7. [REQ] Core Web Vitals: LCP ≤2.5s (poor >4.0s), INP ≤200ms (poor >500ms), CLS ≤0.1 (poor >0.25). Mobile-first. Measure via PageSpeed Insights API + CrUX. INP replaced FID March 2024. ⛔ NEVER reference FID.
8. [REQ] Additional Perf: TTFB ≤800ms (poor >1800ms), FCP ≤1.8s (poor >3.0s). Compression (gzip/brotli), caching headers (Cache-Control, ETag), minification (CSS/JS/HTML), resource hints (preload, prefetch, preconnect).
9. [REQ] URL Structure: Clean, kebab-case, <75 chars, max 3 levels deep. ⛔ underscores, uppercase, session IDs, >3 query params, file extensions (except .html/.php legacy).
10. [REQ] Mobile: Responsive design, viewport meta, touch targets ≥48px, font size ≥16px, content parity (mobile-first indexing since 2019). No horizontal scroll. No interstitials.
11. [REQ] Security: HTTPS everywhere (redirect HTTP→HTTPS), HSTS (`Strict-Transport-Security: max-age=31536000; includeSubDomains; preload`), CSP, X-Frame-Options, X-Content-Type-Options. ⛔ mixed content, HTTP resources on HTTPS page.
12. [REQ] Redirects: 301/308 permanent, 302/307 temporary. Max 1 hop (3 absolute). ⛔ redirect chains >3, redirect loops, meta refresh, JavaScript redirects for SEO-critical pages.
13. [REQ] Images: Alt text (descriptive, not keyword-stuffed), width/height attrs (prevent CLS), lazy loading (`loading="lazy"`), modern formats (WebP/AVIF), <100KB per image. IPTC `TrainedAlgorithmicMedia` label for AI-generated images (Merchant Center requirement).
14. [REQ] Content Quality: Flesch reading ease 60-70. Word count floors: homepage 500, blog 1500, product 300+, landing 800+. No thin content (<60 content score). Duplicate detection via content hash (SHA-256).
15. [REQ] E-E-A-T: Experience (original research, first-hand photos), Expertise (credentials, technical depth), Authoritativeness (external citations, brand mentions), Trustworthiness (contact info, HTTPS, date stamps, corrections — highest weight per Google). AI content: acceptable if helpful, flag low-quality markers.
16. [REQ] Internal Links: Descriptive anchors (not "click here"). Orphan page detection (zero inlinks). Link graph analysis. Broken link detection (4xx/5xx). Nofollow only for paid/UGC. Max 100 links/page.
17. [REQ] GEO/AEO: Citability blocks 134-167 words self-contained. Question-based headings. Short paragraphs. Tables/lists for structure. Multimodal (+156% AI selection with text+images/video). Recency <3 months = 3x more citable. Brand mentions > backlinks (3x in AI search). AI crawler access via robots.txt. llms.txt optional (Google ignores for rankings).
18. [REQ] Crawl Budget: Server log analysis (Nginx/Apache). Bot verification via official IP ranges (Google: googlebot.com DNS, Bing: bing.com/toolbox/bingbot.json, OpenAI: 3 ranges). 90+ bot signatures. Status code distribution per bot. URL pattern segmentation. Verified vs unverified distinction.
19. [REQ] Indexing: `noindex` for thin/duplicate/search-result pages. `index` for canonical. Pagination via `rel="next"`/`rel="prev"` or canonical to view-all. Faceted nav: `noindex` duplicate facets. XML sitemap coverage check.
20. [REQ] IndexNow: Submit URLs to Bing/Yandex/Naver via IndexNow API. Batch submission. Key in robots.txt or root.
21. [REQ] Social Meta: Open Graph (og:title, og:description, og:image, og:url, og:type, og:site_name). Twitter Cards (twitter:card, twitter:site, twitter:creator). Canonical URL for social.
22. [REQ] HTML Validation: DOCTYPE html, charset UTF-8, `<html lang="...">`, `<head>` integrity, document size <2MB. Semantic HTML5 (`<article>`, `<section>`, `<nav>`, `<aside>`, `<header>`, `<footer>`, `<main>`).
23. [REQ] Accessibility (SEO overlap): WCAG: lang attr, form labels, empty buttons/links, heading hierarchy, ARIA, skip nav. Semantic HTML for AI comprehension.
24. [REQ] JavaScript SEO: SPA detection (empty `<div id="root">`, single bundle). Raw vs rendered DOM diff for title/description/canonical/H1/content/links. SSR preferred for SEO-critical pages. December 2025 JS SEO guidance.
25. [REQ] Health Score: 0-100. Weights: Technical 22%, Content 23%, On-Page 20%, Schema 10%, CWV 10%, AI Search 10%, Images 5%. Penalty: CRITICAL -8, WARNING -3, INFO -1. Floor 0, ceiling 100.
26. [REQ] Audit Rules: 251 rules across 20 categories. Core 12%, Performance 12%, Links 8%, Images 8%, Security 8%, Technical 7%, Crawlability 5%, Schema 5%, JS Rendering 5%, Content 5%, Accessibility 4%, Social 3%, E-E-A-T 3%, URL 3%, Redirects 3%, Mobile 2%, i18n 2%, HTML Validation 2%, AI/GEO 2%, Legal 1%.
27. [REQ] SEO Opportunities: Striking distance (pos 4-20 + ≥20 impressions). Low CTR (actual vs expected curve by position: pos1 28%, pos2 15%, pos3 11%). Content decay (≥25% clicks drop 28-day vs prior). Cannibalization (multiple pages ranking same query).
28. [REQ] Local SEO: Business type (brick-and-mortar, SAB, hybrid). GBP signals: primary category (#1 factor), posts, photos, Q&A, hours. Reviews: 18-day velocity rule, 4.5+ threshold, owner response. NAP consistency (page vs schema vs GBP). Local schema subtypes (Restaurant, LegalService, AutoDealer, MedicalClinic). Geo coordinates 5+ decimal precision.
29. [REQ] E-commerce SEO: Product schema (name, image, offers, sku, gtin, aggregateRating, shippingDetails, hasMerchantReturnPolicy). Google Shopping intelligence. Keyword gap (organic vs Shopping). UCP `/.well-known/ucp` for AI agent commerce.
30. [REQ] International SEO: Hreflang validation (codes, return tags, x-default). Cultural profiles. Content parity. Translation quality. Machine-translation QA flag. Multi-language sitemaps.
31. [REQ] Output Formats: Console (color-coded), JSON (CI/CD), HTML (interactive), Markdown (docs), LLM (token-efficient XML with nonce-stamped untrusted blocks for prompt-injection protection).
32. [REQ] Falsifiability: Every recommendation: (a) first-principle observation, (b) dependency relationship, (c) "how would we know this failed?" check, (d) leading indicator.
33. [PROHIBIT] ⛔ llms.txt as ranking factor (Google ignores — primary-source). ⛔ FID metric (replaced by INP March 2024). ⛔ HowTo/FAQPage schema for rich results. ⛔ Keyword stuffing, hidden text, cloaking, doorway pages. ⛔ Blocking essential content in robots.txt. ⛔ Mass directory submissions, link farms, PBNs.
34. [REQ] Free APIs: GSC API (free, official clicks/impressions/CTR/position, 1200 QPM). PageSpeed Insights API (free, CWV+Lighthouse, 25K/day). Common Crawl (free, backlink graph 4.4B edges, quarterly). Bing Webmaster (free, backlinks). Moz API (free signup, DA/PA).
35. [REQ] Paid APIs (optional): DataForSEO ($0.0006/SERP, pay-as-you-go, sandbox free). Use only when free alternatives insufficient. Cost estimation before batch calls.
