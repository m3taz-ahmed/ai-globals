[TECH] ga4-1
[OBJ] Google Analytics 4 (GA4) — free web/app analytics + measurement. Data API + Measurement Protocol + EU endpoint for GDPR. Rules for aiZee marketing-analytics / marketing-strategy skills.
[RULES]
1. [REQ] Free tier: GA4 is free (no hit limit for standard property). Default analytics for every aiZee marketing plan. Paid 360 only when enterprise SLA needed.
2. [REQ] Data collection: gtag/`gtag.js` or GA4 `events` (config + event). Measurement Protocol (`/mp/collect`) for server-side/backend events (purchases, signups) — requires `client_id` + `api_secret`.
3. [REQ] Data API v1 (REST, `analyticsdata.googleapis.com/v1beta`): `properties/{id}:runReport`, `:runPivotReport`, `:runFunnelReport`, `:runRealtimeReport`, `:batchRunReports`. Auth: OAuth2 / service-account JSON. Python: `google-analytics-data` (`BetaAnalyticsDataClient`).
4. [REQ] runReport: dimensions (city, sessionSource, eventName, `language`) + metrics (sessions, conversions, eventCount, activeUsers). Date ranges (today, 7daysAgo, 28daysAgo). Always page via `limit`/`offset` for large pulls.
5. [REQ] runFunnelReport: define `Funnel` steps (event + filter); get step completion + drop-off. Maps to `marketing-strategy` TOFU/MOFU/BOFU funnel.
6. [REQ] GDPR/EU: set EU data endpoint / EU consent mode (`gtag consent` default denied, update on opt-in). For EU residents prefer EU storage region. Honor consent before firing tags (see `marketing-compliance`).
7. [REQ] Conversions/attribution: mark key events as conversions; GA4 uses data-driven attribution. Export cost/CAC to `marketing-analytics` attribution model.
8. [REQ] Language/Arabic: capture `language` dimension (`ar`, `en`); segment Arabic cohorts for RTL reporting parity. Set `language` param on config.
9. [REQ] Events for email: link Brevo/listmonk (brevo-1/listmonk-1) sends → GA4 via UTM `source/medium` + Measurement Protocol purchase events for closed-loop attribution.
10. [REQ] Quotas: Data API ~25K tokens/day (free), 10 QPS; batch reports to stay under. Respect `quotaRemaining`.
11. [REQ] Approval gate: read-only by default. Any server-side `Measurement Protocol` write of conversion needs opt-in/consent; no PII in event params.
12. [PROHIBIT] ⛔ Send PII (email/name) as event params. ⛔ Fire tags before consent (GDPR). ⛔ Store service-account JSON in code/logs/commits. ⛔ Exceed Data API quota without batching.
13. [CMD] Context7: `googleanalytics/ga4-data-api`.
14. [REQ] Free-first note: default over Mixpanel/Amplitude paid; pair with PostHog (MIT, self-host) only when product analytics needed.
