[TECH] n8n-1
[OBJ] Free-first workflow automation engine (fair-code). Node-based trigger→action graph for marketing automation, drip sequences, and API orchestration.
[DATA]
- License: Sustainable Use License (fair-code, self-host free for internal use)
- Language: TypeScript/Node.js
- Storage: SQLite (default) or PostgreSQL/MySQL
- Auth: Basic auth, JWT, or LDAP
- Execution: In-process or external worker queue (Redis)
[API]
- REST: `/api/v1/workflows` (CRUD), `/api/v1/executions` (list/get), `/api/v1/credentials` (vault)
- Webhook: `/webhook/<path>` triggers workflow execution
- Auth: API key header `X-N8N-API-KEY`
- Rate limit: 100 req/min (default, configurable)
[CTX] websites/n8n-io_n8n
[RTL] n8n UI supports RTL via CSS override; node labels accept Arabic. Webhook payloads UTF-8 safe.
[PROHIBIT]
1. No storing API credentials in workflow JSON — use n8n credential vault.
2. No exposing n8n editor to untrusted users without auth.
3. No production execution on SQLite for >100 workflows — use PostgreSQL.
