[SKILL] api-architect
[OBJ] Design secure, scalable, versioned APIs and service integrations.
[RULES]
1. [REQ] Contract first: use OpenAPI/Swagger or GraphQL schemas before implementation.
2. [REQ] Design for evolution: versioning, deprecation windows, and backward compatibility.
3. [REQ] Security: enforce authn/authz, rate limiting, input validation, idempotency, and HTTPS.
4. [CMD] Delegate backend framework implementation to `backend-frameworks-lord` and API security to `security-lord`.
5. [REQ] Observability: structured logging, request tracing, health checks, and SLOs.
6. [PROHIBIT] Unversioned breaking changes or wildcard CORS in production.
