[WORKFLOW] 40-productized-service
[OBJ] Standardize→package→landing→sell flow that converts a custom freelance service into a fixed-scope, fixed-price productized offer ready for repeat selling and referral.
[TRIGGER] productize | خدمة جاهزة | packaged service | productized | بيع متكرر | SOP
[RULES]
1. [REQ] Standardize: extract a repeatable SOP from the user's best custom engagements (inputs, steps, outputs, timeline).
2. [REQ] Package: define fixed scope, price, and deliverables. Hand off to `pricing-strategy` for the package rate.
3. [REQ] Landing: draft a bilingual landing page (problem→offer→CTA) referencing `cro-optimization` for conversion.
4. [REQ] Sell: create an auto-sell path (checkout/quote→contract→invoice via `invoice-manager`). Approve before any publish.
5. [REQ] Referral: add a referral/upsell step to the delivery. Record the productized offer in `Memory.md`.
6. [REQ] Approval gate: no landing page publish, no offer listing, without explicit user approval.
[PROHIBIT]
1. No landing page publish, offer listing, or contract/invoice without explicit user approval.
2. No misrepresentation of scope or guarantees beyond the fixed package.
3. No ToS violations on listing platforms.
4. Respect marketing-compliance: opt-in capture, unsubscribe, GDPR on any lead collection.
